# Verbraucherfenster Hessen – Bot 🚀

Dieses Repository enthält die Informationsseite für den inoffiziellen Telegram-Bot zum Verbraucherfenster Hessen.

👉 **Zur offiziellen Webseite:** [Hier klicken](https://telegramtrainer.github.io/Verbraucherfenster/)
👉 **Direkt zum Telegram-Bot:** [@VerbraucherfensterBot](https://t.me/VerbraucherfensterBot)

---

## Über das Projekt
Dieses Projekt bietet eine tippfehlertolerante Suchfunktion, automatische Regionen-Benachrichtigungen und einen transparenten Verbraucher-Index für die in Hessen nach **§ 40 Abs. 1a LFGB** veröffentlichten Hygiene- und Lebensmittelmängel.

*Die vollständigen Details und Vorteile findest du auf unserer Webansicht oder direkt im Bot!*
